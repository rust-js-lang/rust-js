# 0740. A function's members are read of any function, `js::function`

Status: Accepted. Extends [0653](0653-a-js-function-value-is-a-dyn-fn-of-its-signature.md)
and [0700](0700-typescripts-function-gives-any-value.md): what a JS
function value has besides its call.

Extended by [0848](0848-apply-is-functions-and-its-this-may-be-null.md):
`function::apply`, its `this` `null` too.

Case ([0262](0262-when-rust-and-js-disagree.md)): N: each is the JS
property itself, read of the function JS has.

## Context

React's `shared/ReactPerformanceTrackProperties.js` reads a function's
name, its count of parameters and its source:

```js
const functionName = value.name;
..
prevValue.name === nextValue.name && prevValue.length === nextValue.length
..
const prevSrc = Function.prototype.toString.call(prevValue);
```

TypeScript types them on `Function`, which every function type has:
`name: string`, `length: number`, `toString(): string`. The js crate bound
none of them, so the port read `js::get(js::unknown(f), "name")`, an
`Option<&Unknown>` it then classified, and couldn't write the source
comparison at all.

## Decision

**`js::function` binds `Function.prototype`'s members, each of a function
of any signature, `F: js::AnyFunction<M> + ?Sized`**, as `js::string`
binds a `str`'s, with its first parameter `this`:

| Rust | JS | TypeScript |
|---|---|---|
| `function::name(f)` | `f.name` | `name: string` |
| `function::length(f)` | `f.length` | `length: number`, a count, `u32` |
| `function::to_string(f)` | `Function.prototype.toString.call(f)` | `toString(): string` |

```rust
Kind::Function(f) => {
    let function_name = function::name(f);
    ..
}
```
```js
case "function": {
  const functionName = value.name;
```

- **`AnyFunction<M>` is any function**: a function item, a closure, a `fn`
  pointer and a `dyn Fn` of any signature, `M` its signature, rustc's to
  infer, as `AnyShape`'s function impls are; generated by the same macro,
  one list of arities. A value that's no function isn't one, so `name` of
  text is rustc's error, where `AnyShape` would take it.
- **The source is read through `Function.prototype`**, as upstream reads
  it, so a function's own `toString`, which a class may have, changes
  nothing: `Object.prototype.toString.call` is the same form for objects.

## Why

- **TypeScript's own types**, of what every function has: one binding of
  each member for every signature, as TypeScript's `Function` is every
  function type's.
- **The JS upstream writes**: no property read by name, no `String(..)`.

## Alternatives

- **Of `&dyn Fn() -> Option<&'static Unknown>` alone, ADR 0700's
  `Function`**: a `dyn Fn(&str)` isn't one, so a function of a known
  signature would be cast to read its name.
- **A trait whose methods they are, `f.name()`**: a member read as a
  method of an imported trait, where `js::string::length(text)` is the
  form already, of a type Rust owns.
- **`length` an `f64`**: TypeScript's `number`, but a count is a `u32`, as
  `string::length` and `RegExpMatch::length` are.

## What holds it

- `test/js-object.test.ts`, "a function's name, length and source are read
  of any function": each of a `Kind::Function`, a `dyn Fn(&str) -> u32`
  and a function item, run.
- The guide's [JS values](../guide/interop/types.md#js-values-jsobject-and-unknown).
