# Decisions

The index of rust-js's design decisions, each a record of what we decided,
why, what we rejected, and what it costs, in its group. Each is listed
once; a superseded or replaced one says so on its line
(`test/architecture.test.ts`). Lines are only added or edited, never
reordered, and git merges this file by keeping both sides' lines
(`.gitattributes`), so two changes adding decisions at once both land.

## Adding a decision

Copy the shape of an existing record: **Context → Decision → Why →
Alternatives → Consequences**. Number it with `bun run adr:next`, the next
number neither `main` nor this branch has; if `main` takes it before you
push, `bun run adr:renumber <from> <to>` moves yours, and each line this
branch added that names it. If a new decision replaces an old one, don't
delete the old one. Set its status to `Superseded by NNNN`, so the history
of *why* survives. Link it from its group above, and mark the old one's
link *(superseded by NNNN)*: `test/architecture.test.ts` checks that each
is linked once, each superseded or replaced one marked, and no two share
a number.
