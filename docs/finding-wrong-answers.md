# Finding wrong answers

A wrong answer hides where nothing compares the JS with native Rust. This
page lists the techniques that have found wrong answers, what each found,
and the lessons behind them, so the next net is built on what worked.
[TESTS.md](../TESTS.md) is the authority on which suites exist and what
they cost; [bug-kinds.md](bug-kinds.md) on how a bug is classified once
found. This page is about **how bugs are found**.

When a new technique finds a wrong answer, or a wrong answer is found that
none of these would have, add it here in the same commit as the fix.

Each P0 carries the net that found it, a `found-by:` label
([bug-kinds.md](bug-kinds.md#found-by)); `bun scripts/found-by.ts` counts
them by net and week. Of the 357 P0s of 2026-11-01 to 2026-11-10, 144
were found by an audit beside another fix, 76 by the tables, 57 by the
metamorphic net, 23 by the ports, 11 by the consumer net, and 30 don't
say.

## The techniques

| Technique | Where | What it found | Why it works |
|---|---|---|---|
| Decision coverage: which answers of the compiler's decisions the nets' programs reach | `bun run decision-coverage` (ADR 1124, `src/decisions.rs`): each decision's owner counts its answers where it gives them, every net runs with `RUST_JS_DECISIONS`, and the report lists the answers no program reaches, and those one build, one shape or one net alone reaches | Each nightly's `decision coverage` job; its first gap, 2026-11-11: `writer-options`' `shown` | A wrong answer hides where no program reaches a decision's answer, however many run: #1349's overlapping swap was one no generator wrote. A gap is measured, then a template or a case is written for it |
| Rustlantis's custom MIR programs, natively on wasm32 and as JS | `test/rustlantis.test.ts` (ADR 1125), the nightly's 200 seeds | #1380 (a wide literal cast through a lossy `Number`), #1381 (a raw pointer to a by-value parameter), #1382 (custom MIR's local used before it's written, refused), #1383 (rust-js's stack), 2026-11-11 | Programs of MIR, UB-free by construction, reach shapes of places, casts and calls no template or case writes; each failure is asked whether ordinary Rust reaches it, as both P0s did |
| A corpus case per behaviour, run against native in both builds | `test/corpus/`, `test/corpus.test.ts` | Most fixes' first proof | Each case pins one behaviour against native, not against a snapshot |
| Generated tables of every combination | The iterator matrix (107k cases) and conformance table (21k), ADR 1090/1092, `test/iterator-matrix.test.ts` | Most of the iterator P0s since 2026-11-04; 23 of the last 30 iterators × protocol gap issues | Combinations nobody would write by hand: source × adapters × consumer |
| Panic points | `ITERATOR_TABLE=points` (#817): every closure call, item drop and source drop is the k-th event, with one panic per run | #843–#846 on its first run | Unwind paths are rarely written by hand and are where drop orders differ |
| Panic points beyond iterators | `ITERATOR_TABLE=unwind` (#854, `test/unwind-points.ts`): 16 families of operations × 11 shapes of value, each make, drop, clone and comparison of a `D` and each closure call the k-th event, by #817's runner and oracle | 16 P0s on its first run (#897–#912), 591 of 3,470 cases: partial clones, fill values and the rest of an `extend` leaked; a map's `clear` and a `BinaryHeap`'s and the unstable sorts' holes dropping twice; derived `Default`s and combinators' `self` leaked; and five with no panic at all, `HashMap::retain`'s drop of a handle, `VecDeque::retain_mut`'s eager drops, `Rc`'s `==` by pointer, and the order a stable sort, a `BTreeMap` and `max` call the crate's `Ord` | A comparison that prints is a point too: what calls the crate's `Ord`, `Eq` or `Clone`, and in what order, is as observable as a drop |
| std's methods past its iterators: each stable method of its collections, slices, strings and cells that changes what it's called on or calls what it's given, read from std's own source, run on loud items as it is and with its closure's, comparison's or hash's call panicking | `ITERATOR_TABLE=std` (#1171, `test/std-net.ts`) | #1267 and #1268 on its first run: an `insert` past the end that never dropped what it took, a `String::retain` that left its text whole as it panicked | What std leaves in place as a panic unwinds, and what it drops, is rarely written by hand |
| The runtime's helpers against std's own bodies, no native run | `ITERATOR_ORACLE=std` (#1205, ADR 1122, `test/twin-net.ts`): the plain build judged against the build of std's iterator structs, case by case; per push of the iterators' code | None on its first run, of every table (129,843 cases judged); it names the 231 helpers no build of std's bodies pits yet | Two copies of std, the runtime's and std's own, run the same loud programs; half the cost of a native run, so a push runs every table but the matrix whole |
| A fixed table row grown by hand: more items, all equal | Beside a fix of the unwind table's rows, a probe of the same operation with three entries that each print alike (`D(1)` thrice), so an unspecified walk order can't change the lines | #920 (hashbrown stops at a panicking drop, the table's one-entry `HashMap` rows can't show it), #921, #922, while fixing #899–#919 | A table's shapes are small; what happens to the rest after the first panic needs a rest, and equal items keep a hash map's order out of the answer |
| A full run, not a sample | `ITERATOR_MATRIX=all`, `bun run nightly` | #823, #834, #835, #833: fix-on-fix regressions the sampled slices passed | A fix that makes a shape compile exposes every path through it |
| Rebatching: the same rows in other company | #818's `pairs` and rows a change names | #850, wrong only beside another function using the same type | Crate-wide and per-type facts leak between unrelated functions |
| Matrices of one owner's forms × what meets them | `test/mut-ref-matrix.test.ts`, 210 programs of `MutRefForm`'s pointees × holders × 14 operations (ADR 1086); `test/none-matrix.test.ts`, 580 programs of `NoneForm`'s places × payloads × writers × 9 readers (ADR 1096); both builds (#855) | The `&mut` matrix's growth: none, every program as native Rust; the `None` matrix's first run: #957 (a nested nullable field written from a nullable function's `None` read `Some(None)`) and #958 (a temporary `Cell`'s `take` crashes) | A form is one owner's answer, but each writer and reader asks it apart; the space of form × writer × reader is small enough to run whole, and a writer of one form meeting a reader of another is where they disagree |
| Metamorphic rewrites: each corpus case rewritten in ways that keep its meaning | `test/metamorphic.test.ts` (#939, ADR 1104): `scripts/metamorph`, a `syn` rewriter, outlines `main`, boxes each `let`, takes each reference and owned parameter through an identity trait, `&dyn`, `&impl` and `impl`; round 2 (#1008) moves each `let` into an `Option`, an `Rc<RefCell>` and a struct's field, makes a function generic over a type it takes, a closure a `fn` and a function value a closure, and moves the case's items into a library crate; native Rust's run of the rewrite is its oracle | Its first run: 126 cases in four families, a type parameter's value reached through a trait method stepped without its dictionaries, a write through a `&mut dyn` lost, and more. | Generic code given other instances: each consumer and adapter of an iterator the case makes called in generic code, given a `filter`, a `chain`, a `map`, a `fuse` or the net's own iterator in place of the case's; and each value the case clones, makes a `Some` of, drops or copies out of a reference, done in generic code of its type | `test/metamorphic.test.ts`' `generic-instances` (#1237, ADR 1104): `metamorph_generic::at_k(..)`, each place narrowed to what rustc accepts (`narrow.rs`) | Its first run, 118 s in 12 parts: 65 cases. 54 are generic code's `collect()` into a `B: FromIterator`, which isn't std's `Vec` collect: no hint asked, another capacity, other in-place and unwinding drops (#1239). ## The lessons

1. **Generate the space; don't sample it by hand.** Every large find
   came from a generated table: adapter × consumer × source, or every
   panic point. A hand-written case covers what someone thought of.
2. **Context is part of the input.** An answer that depends on another
   function in the crate, a per-type or crate-wide fact, is a bug class of
   its own (#823, #834, #850). Test the same rows in other company, and
   prefer facts per value over facts per type (#814, #851).
3. **A refusal is safe; a shape that newly compiles is where wrong answers
   start.** Run the full rows of whatever a fix makes compile (#818's
   gate), not the sample.
4. **Unwind paths are where orders differ.** Inject a panic at every
   point: closures, drops, the source's drop. A second panic during
   unwind aborts in Rust (#847), so a table's cases never panic of
   themselves (an `unwrap` of `None`), only at their point.
5. **Equivalence needs the full rows.** Before removing code whose
   mutation survived, run every row of every adapter it decides for.
6. **Every accepted difference is a claim to re-test.** ADR 0262 allows
   an exception only by the user's decision; an agent's "harmless" isn't
   one.
7. **Two oracles beat one.** Native is the oracle; a second lowering of
   the same program (`--std-iterators`) finds bugs one build hides.
8. **A program all refused passes all.** A table whose shared prelude
   rust-js refuses refuses every case, and a refusal passes. The harness
   fails a batch whose every case is refused (#854's first run of its
   keyed maps passed so, in 392 s).
